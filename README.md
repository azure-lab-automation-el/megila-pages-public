# Megila encrypted runner

This public repository contains the workflow launcher and an age-encrypted application package. The original repository and full history remain private. No document content is stored here. Source packages can be decrypted only by the repository's Actions secret. The app processes PDFs locally in the browser; deployments remain manual.

`main` is the production track. `epub-preview` is the experimental QA branch. The workflow keeps production deployment manual and restricted to `main`.
